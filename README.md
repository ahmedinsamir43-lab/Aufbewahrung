# Nährwert

Persönlicher Ernährungs-Tracker für Android (Expo / React Native / TypeScript).

## Entwicklung

```bash
npm install
npm test            # Unit-Tests
npm run typecheck   # TypeScript
npm run lint        # ESLint
npm run android     # Development Build auf angeschlossenem Gerät (expo run:android)
```
